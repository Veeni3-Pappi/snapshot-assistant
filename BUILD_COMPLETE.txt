🚀 QUICK START INSTRUCTIONS:

STEP 1: CONFIGURE
  Edit .env file with:
    - ANTHROPIC_API_KEY (from https://console.anthropic.com/)
    - EMAIL_USER and EMAIL_PASSWORD (Gmail app password)
    - REPORT_RECIPIENT_EMAIL (where to send reports)

STEP 2: INSTALL
  $ npm install

STEP 3: START
  $ npm start

STEP 4: ACCESS
  Desktop: http://localhost:3000
  Mobile:  http://YOUR-IP:3000 (run: npm run ip)

STEP 5: USE
  1. Upload CCTV snapshots
  2. Upload Daily Book (optional)
  3. Upload Payment Records (optional)
  4. Click "Analyze"
  5. Click "Generate & Email Report"
