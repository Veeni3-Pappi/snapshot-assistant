📱 TYPICAL WORKFLOW:

1. User uploads files via public/index.html
   ↓
2. Express (server.js) receives uploads
   ↓
3. Files stored in memory (sessionData)
   ↓
4. User clicks "Analyze"
   ↓
5. server.js sends all images to Claude API
   ↓
6. Claude analyzes and returns text report
   ↓
7. Results displayed in browser
   ↓
8. User clicks "Generate & Email Report"
   ↓
9. server.js formats as HTML
   ↓
10. Nodemailer sends via SMTP
    ↓
11. Report arrives in email inbox
